HYBRID CRYPTOGRAPHY

How HYBRIDCRYPT works.

HYBRIDCRYPT combines symmetric AES encryption with asymmetric RSA encryption to protect both the data and its session key.

THE TWO ALGORITHMS

AES + RSA

Each algorithm has a different job in the hybrid encryption system.

01
🔐

AES

AES encrypts the actual message or file using a randomly generated session key.

02
🔑

RSA

RSA encrypts the AES session key using the recipient's public key.

03
🛡️

Combined Protection

The encrypted data and protected AES key can be transferred together.

ENCRYPTION FLOW

From plaintext to protected data.

The sender generates an AES session key, encrypts the data, and then uses RSA to protect that AES key.

01

Generate AES Key

A random session key is generated.

02

Encrypt Data

AES encrypts the original message.

03

Protect AES Key

RSA encrypts the AES session key.

04

Decrypt

RSA recovers the AES key and AES decrypts the original data.

COMPLETE WORKFLOW

Sender → Encryption → Receiver

01

Sender

Provides the message or file.

02

AES

Encrypts the actual data.

03

RSA

Protects the AES session key.

04

Receiver

Recovers the key and decrypts the data.
